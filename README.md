## Data pipeline

- **Discovery** reads public competitor catalogs plus GitHub topic/search results and updates `data/repositories.json`.
- **Ranking** refreshes GitHub metrics for the known repository pool, stores a daily snapshot, and updates the rankings above.
- Competitor catalogs are used only as public discovery seeds. Ranking metrics are fetched independently from GitHub.
